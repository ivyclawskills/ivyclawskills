# IvyClaw

**Explore your interests. Find an opportunity worth taking.**

IvyClaw helps students discover summer programs, competitions, internships, and creative opportunities—with official links for checking current requirements.

## Start exploring

- [Find opportunities](https://www.ivyclaw.cc/en/find)
- [Use the Opportunity Finder Skill](https://github.com/ivyclawskills/skills)
- [Read our guides](https://www.ivyclaw.cc/en/latest)

The free Skill brings opportunity search into a compatible agent, with up to three results per query. Full List purchases and preparation services remain separate website features.
